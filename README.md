# TradeAssist

Job pipeline app for small service businesses. Track leads, quotes, invoices, bookings, customers, and messages — all in one place. Runs in your browser, no install needed.

## Quick Start

1. Open `index.html` in any browser
2. Data saves automatically to your browser
3. For mobile: open in Chrome → "Add to Home Screen"

## Features

- **Dashboard** — At-a-glance ops view
- **Leads** — Intake, qualify, convert to quotes
- **Quotes** — Professional print/PDF estimating
- **Invoices** — Billing with payment tracking
- **Bookings** — Schedule jobs and crews
- **Messages** — Reusable templates for texts/emails
- **Follow-Ups** — Priority task board
- **Customers** — Contact history
- **Reports** — Live business summaries
- **Settings** — Company branding

## Tech

Pure HTML/CSS/JS — no server, no database, no signup. All data stays in your browser's localStorage.
